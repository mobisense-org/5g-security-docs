# Denial of Service (DoS)

DoS spans the radio, RRC, and core layers — from trivial radio-layer jamming that any SDR operator can execute, to core-network crashes requiring protocol-level knowledge.

## Why This Category Is So Large

5G's radio interface is inherently broadcast-based: the UE must listen to unprotected synchronization and system information before any security context exists. This creates a fundamental asymmetry where an attacker with a cheap SDR and power amplifier can deny service to many users simultaneously.

At the core-network layer, the shift to software-based network functions (Open5GS, OAI, Magma) has introduced traditional software vulnerabilities -- buffer overflows, null-pointer dereferences, malformed packet crashes -- that map directly to DoS.

## Common Hardware

- **USRP B210** -- sufficient for most radio-layer DoS attacks
- **USRP N310** -- needed for wideband or multi-carrier attacks
- **Power Amplifier** -- required for PRACH/RACH jamming to reach victim cells
- **No extra hardware** -- for core-network attacks (AMF crash, fuzzing-based DoS)
