## REST API Injection

5G Service-Based Architecture uses HTTP/2 REST APIs between Network Functions. Open5GS exposes these APIs, and testing reveals:
- Missing TLS encryption on SBI (Service-Based Interface)
- No rate-limiting on AMF/NRF requests (DDoS exposure)
- SQL/NoSQL injection on database interfaces
- Input validation gaps

**Replication:** Use standard pentest tools (Burp Suite, OWASP ZAP) against your Open5GS REST APIs. No SDR hardware needed — purely network-level testing.

## Token Abuse (FivGeeFuzz)

Grammar-based fuzzing framework discovers flaws in 5G core SBI where tokens can be reused across services, enabling unauthorized access between NFs.
