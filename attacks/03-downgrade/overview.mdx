## Why It's #3

Downgrade attacks exploit the backward-compatibility requirement of mobile networks. Even a 5G-capable UE can be forced to use 2G (no mutual authentication, weak ciphers) or to negotiate null encryption. These attacks are practical because operators still deploy 2G/3G for coverage and inter-RAT handovers lack cryptographic binding.

## 5G vs 4G: What Changed

| Aspect | 4G (LTE) | 5G (NR) |
|---|---|---|
| Inter-RAT redirect | RRC redirect to 2G/3G | Still possible (redirectedCarrierInfo in RRC Release) |
| Cipher negotiation | EEA0 common | NEA0 should be banned but still supported by some UEs |
| Integrity protection | Optional on UP | Mandatory on CP, optional on UP |
| Bidding-down defense | UE Security Capabilities IE | Same mechanism — but rogue gNB can strip it |
