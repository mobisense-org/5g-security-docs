## Attack Mechanism

SIB1 (System Information Block Type 1) is broadcast by every 5G NR cell and carries essential parameters for cell access: PLMN identities, cell barring status, scheduling of other SIBs, and initial access configuration. **SIB1 is not integrity-protected or authenticated** in any release of 3GPP specifications.

```
1. Attacker deploys USRP B210 + PA on target frequency (SSB/ARFCN)
2. Transmits a spoofed SIB1 with higher power than the legitimate cell
3. Options:
   a. Set cellBarred = barred → UE cannot access the cell (DoS)
   b. Modify PLMN list → redirect UE to rogue PLMN
   c. Alter SIB scheduling → UE cannot decode further SIBs (soft DoS)
   d. Change tracking area code → force TAU procedure
4. UE reads the stronger (spoofed) SIB1 and acts on it
```

<Warning>
SIB1 authentication has been discussed in 3GPP Rel-18+ but no mandatory mechanism is deployed as of Rel-17. All commercial 5G networks remain vulnerable.
</Warning>

### Why It Works
- SIB1 is decoded before any security context is established
- UE has no way to verify the source of broadcast information
- The strongest signal wins (capture effect)

## Replication

| Component | Requirement |
|---|---|
| SDR | USRP B210 (or X310) |
| Amplifier | External PA for outdoor range (20-30 dBm output) |
| Software | Modified srsRAN 5G or OpenAirInterface for SIB1 crafting |
| Shielding | RF shielded box for lab testing (optional) |

<Tip>
Start in a shielded environment. SIB1 spoofing on live frequencies without authorization is illegal in most jurisdictions.
</Tip>
