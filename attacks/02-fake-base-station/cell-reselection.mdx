## Attack Mechanism

Cell reselection is the process by which a UE in RRC_IDLE or RRC_INACTIVE mode selects a new cell to camp on. The UE evaluates cells based on signal strength (RSRP), signal quality (RSRQ), and priority parameters broadcast in SIBs. None of these are authenticated.

```
1. Attacker identifies the target cell's frequency (ARFCN) and PCI
2. Deploy rogue gNB on the same frequency with a different PCI
3. Transmit at higher power than the legitimate cell
4. UE's cell reselection algorithm ranks the rogue cell higher:
   - S-criteria: Srxlev > 0 and Squal > 0
   - R-criteria: Rs (serving) < Rn (neighbor) + Qhyst
5. After Treselection timer expires (typically 1-2 seconds), UE reselects
6. UE camps on rogue cell
```

### Forcing Techniques
- **Power advantage**: Simply transmit stronger than the legitimate cell
- **SIB manipulation**: Broadcast SIB2/SIB3 with favorable reselection parameters
- **Frequency priority**: Use SIB-advertised inter-frequency priority to lure UEs

<Warning>
Cell reselection attacks work on UEs in IDLE mode. For UEs in CONNECTED mode, the attacker must first trigger an RRC release or wait for the inactivity timer to expire.
</Warning>

## Replication

| Component | Requirement |
|---|---|
| SDR | USRP B210 |
| Amplifier | External PA (to achieve power advantage) |
| Software | srsRAN gNB or OAI gNB with configurable SIB parameters |
| Test UE | COTS 5G phone + SIM for test PLMN |
| Shielding | RF shielded box for controlled testing |

<Tip>
Monitor the UE's cell camping state using diagnostic tools (e.g., Network Signal Guru on rooted Android) to confirm reselection occurred.
</Tip>
