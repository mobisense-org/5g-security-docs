Signal overshadowing injects crafted signals that overpower legitimate broadcasts. Unlike fake base stations (which need 35+ dB), overshadowing needs only a few dB advantage.

The foundational SigOver (2019) and AdaptOver (2021) papers established the technique. 5Gone extends it to the **uplink** direction in **5G Standalone** for the first time.
