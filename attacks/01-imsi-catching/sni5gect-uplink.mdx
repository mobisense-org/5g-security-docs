## Attack Mechanism

Unlike SUCI-catcher (which requires a rogue gNB), SNI5GECT works as a **passive third-party observer** that sniffs pre-authentication uplink messages.

```
Legitimate gNB                    Victim UE
      |                               |
      |<===== Pre-auth messages ======>|
      |                               |
      |     [Attacker B210]           |
      |     Passive sniffing          |
      |     of uplink channel         |
      |                               |
      |  Captures:                    |
      |  - RRCSetupRequest            |
      |  - Registration Request       |
      |  - UE identity (>70% success) |
```

### Key Innovation
- Does **NOT** require operating a rogue base station
- Sniffs both downlink AND uplink pre-auth messages
- Can also **inject** downlink messages (separate capability)

### Success Rates
| Operation | Rate | Range |
|---|---|---|
| Uplink sniffing accuracy | >80% | 20m |
| Downlink sniffing accuracy | >80% | 20m |
| Injection success | 70-90% | 20m |
| UE identity extraction | >70% | 20m |

## Replication Guide

### Setup (Minimal)
```
[USRP B210] ──USB3──> [PC running Sni5Gect]
     │
  [Antenna]
     │
  ~~~OTA~~~  (passive observation of existing 5G cell)
     │
[Legitimate gNB]  ←──→  [Victim UE]
```

### Steps
1. Clone repo: `git clone https://github.com/asset-group/Sni5Gect-5GNR-sniffing-and-exploitation`
2. Build with Docker support (provided)
3. Configure for target 5G NR frequency/band
4. Run in sniffing mode — captures pre-auth MAC-NR messages
5. Use Wireshark integration to analyze captured identities
6. (Optional) Switch to injection mode for active attacks

### Why No Extra Hardware
- Pure passive reception for sniffing mode
- B210 is explicitly supported by the toolkit
- No PA needed (not transmitting)
- No duplexer needed (RX only for sniffing)
